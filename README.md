# Freq Control 1.1 — تحكم بترددات CPU (كل الكلسترات) / GPU / DDR / NPU + حارس حرارة

مصمم لـ **Galaxy S24 Ultra (SM8650)**. يعمل بجزئين:

| الجزء | يتحكم بـ | كيف |
|---|---|---|
| موديول LSPosed داخل `com.sec.android.sdhms` | GPU، DDR، NPU | `SemDvfsManager` (نفس آلية سامسونج) |
| مساعد روت (`freqctl.sh`) | نوى CPU: `0-1` و`2-4` و`5-6` و`7` | كتابة `scaling_min/max_freq` لكل `policy` |

## ليش الإصدار القديم يرفع النواة 7 بس؟
سامسونج داخل SDHMS ما تعرّف إلا مقبضين للـ CPU: `SIOP_ARM_MAX` (النوع 13) و`SIOP_LITTLE_ARM_MAX`.
ما فيه أي نوع للنوى الوسطى، فكان مستحيل توصلها عبر `SemDvfsManager`. الحل: كتابة مباشرة بالروت على كل policy.

## حارس الحرارة
- مقبض تشغيل/إطفاء + حدّين: حرارة المعالج (SoC) وحرارة البطارية.
- إذا تجاوز أحدهما حدّه: يرجّع كل نوى الـ CPU لقيمها الأصلية، ويفك قيود GPU/DDR/NPU. يرجع كل شي تلقائياً لما تنزل الحرارة 5° (المعالج) أو 2° (البطارية) تحت الحد.
- الافتراضي: مفعّل، 85° للمعالج و45° للبطارية.
- إذا أطفيته، ما يمنع السخونة إلا حماية سامسونج والهاردوير.

## التشغيل
1. ارفع المجلد على GitHub (مع `.github`) ← Actions ← Build APK ← Run workflow ← نزّل الـ APK.
2. ثبّت الـ APK. في LSPosed فعّل **Freq Control** على `com.sec.android.sdhms`، وأعد التشغيل.
3. افتح التطبيق واسمح للروت. أول فتح يثبّت المساعد في `/data/adb/freqctl` ويضيف مشغّل إقلاع في `/data/adb/service.d`.
4. اختر النطاق لكل كرت وفعّل المفتاح.

## ملاحظات مهمة
- **ما اختبرته على جهاز حقيقي.** سكربت الروت اختبرته على sysfs وهمي (التطبيق، الحارس، الإطفاء، الاستعادة). كود الجافا ما قدرت أبنيه هنا.
- معرّفات DDR/NPU مأخوذة من كود SDHMS نفسه: DDR max = `0x30001002` و`0x30002000`، NPU max = `0x50001002`. معرّفات الحد **الأدنى** (`0x30001001` للـ DDR و`0x50001001` للـ NPU) **استنتاج بالمقارنة** مع CPU (`0x12001001` min / `0x12001002` max). لو ما اشتغل الأدنى يظهر في الكرت "النظام رفض قيمة الحد الأدنى".
- جدول NPU قد يكون حالات وليس MHz، فالأرقام تظهر كما هي.
- سامسونج ممكن تخفض الحد الأعلى بحماية الحرارة حقها (SIOP). رفع الحد الأدنى لا يمنعها.
- سجل الموديول: LSPosed ← Logs ← `FreqCtl`. سجل جداول DDR/NPU يظهر هناك، أرسله لي لو فيه مشكلة.
- إيقاف المساعد: `su -c "sh /data/adb/freqctl/freqctl.sh stop"` وحذف `/data/adb/service.d/freqctl.sh`.
